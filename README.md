Welcome to Stranger - Armed to the Teeth: a user-friendly game scripting tool. The purpose of this tool is to create a platform to chop-up, rearrange, and remix existing game content in any way you want, with the ability to save your changes and share with others. This tool is made by me, Racewizard, but 100% of the code was written by AI

**Basic Overview of What You Can Do:**
-Create new characters with unique appearances and abilities!
-Create new melee and ranged weapons for enemies with unique effects and traits!
-Create new character-spawns and link them to existing spawn conditions!
-Spawn in any game model anywhere!
-Modify Live-Ammo Types and global combat preferences!
-Modify existing spawn-lists, character-types!

This depends on SWSE:
https://github.com/JohnsonMichaels/OddWorld-Strangers-Wrath-Script-Extender
